What is simulated here? Chunking and the pipeline state are real JavaScript logic in this file. The 24-dimensional vectors are created with deterministic feature hashing, so they mostly capture shared words—not the meaning-rich semantic relationships of a trained embedding model. Retrieval uses cosine similarity. The final “LLM answer” is an extractive mock answer, not an actual model response.
